# 实验室维护记录分类修复

维护记录用于登记实验室日常巡检、环境清洁、设施保养与安全检查，设备关联可选，不走报修派单或验收流程。

应用启动时由 `DatabaseSchemaInitializer` 检查并新增 `repair_order.record_kind` 字段及分类索引。历史表复用存储，业务查询按明确分类隔离，不新增业务表，不删除现有记录：

- `lab_maintenance`：实验室维护；维护列表、详情、修改和删除仅操作这一类。
- `repair`：报修；报修列表、提醒及故障统计仅使用这一类。

首次升级时，原维护表单生成的 `MR-14位时间戳-4位随机数` 记录自动归为 `lab_maintenance`；其他旧记录默认保留为报修。迁移保留记录 ID、编号、内容、结果、逻辑删除状态和原更新时间。

工作台将维护显示为“实验室维护”及“维护记录”，不再显示为“维修工单”。使用此前完整数据库备份恢复后，首次启动新版应用会执行同一兼容升级。
