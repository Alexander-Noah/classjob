# 智云实验室项目架构说明

## 项目概述

智云实验室是一个基于数据驱动的实验室协同管控平台，包含管理端Web平台、教师端桌面客户端和学生端桌面客户端。

## 整体架构

```
智云实验室项目
├── Backend/                    # 后端服务（Spring Boot + MyBatis）
├── web/                        # 前端管理平台（Vue 3 + Element Plus）
├── TvTa-ui-main/              # 桌面客户端（Tauri + Vue 3）
│   ├── 教师端                  # 本地值守客户端
│   └── 学生端                  # 系统托盘客户端
├── Python/                     # Python辅助脚本
├── vosk-model-small-cn-0.22/  # 语音识别模型
└── 材料/                       # 项目文档和资料
```

## 七、关键业务流程

### 7.1 设备资产管理流程

1. **新增设备** → DeviceEditorDialog → useDeviceManagement.submitDevice → POST /devices
2. **设备盘点** → DeviceInventoryDialog → POST /devices/{id}/inventory
3. **设备调拨** → DeviceTransferDialog → POST /devices/{id}/transfer
4. **资产码打印** → DeviceAssetCodeDialog → 生成二维码 → 打印
5. **批量导入** → Excel/CSV → importDevicesFromFile → POST /devices/batch

### 7.2 实验室预约流程

1. 用户选择实验室、时间段
2. 提交预约申请 → POST /lab-reservations
3. 管理员审批 → PUT /lab-reservations/{id}
4. 用户查看预约状态

### 7.3 报修流程

1. 用户提交报修 → POST /repair-orders
2. 管理员分配维修人员 → PUT /repair-orders/{id}
3. 维修人员处理工单 → PUT /repair-orders/{id}
4. 完成维修 → status: 已完成

### 7.4 课程环境管理流程

1. 教师提交环境需求 → POST /course-environments
2. 管理员配置环境 → 安装软件 → 上传截图
3. 教师远程确认 → PUT /course-environments/{id}
4. 环境模板沉淀 → POST /environment-templates

### 7.5 教师端-学生端联调流程

1. 启动教师端 → 开启本地网关（UDP 8888, HTTP 5000）
2. 启动学生端 → UDP广播发现教师端
3. 学生端上报状态 → POST http://教师端IP:5000/api/collect
4. 教师端执行控制 → POST http://学生端IP:5001/api/action

## 八、开发规范

### 8.1 后端规范

- **命名规范**：
  - Controller: `XxxController`
  - Service: `XxxService` / `XxxServiceImpl`
  - Entity: `XxxEntity`
  - Mapper: `XxxMapper`
  
- **API规范**：
  - 统一使用 `Result` 封装响应
  - 成功：`Result.success(message, data)`
  - 失败：`Result.error(message)`
  
- **日志规范**：
  - 使用 `@Slf4j` 注解
  - 请求日志通过 `RequestLoggingFilter` 自动记录

### 8.2 前端规范

- **组件命名**：
  - 页面：`XxxManagement.vue`
  - 弹窗：`XxxEditorDialog.vue`
  - 表格：`XxxListTable.vue`
  
- **API调用**：
  - 统一在 `api/services/` 中封装
  - 使用 `http.js` 实例
  - 错误处理由拦截器统一处理
  
- **状态管理**：
  - 页面级状态使用 Composition API
  - 跨页面状态使用 Pinia（可选）

## 十、常见问题

### Q1: 后端启动报错数据库连接失败？
A: 检查 `application.yaml` 中的数据库配置，确保MySQL已启动且数据库已创建。

### Q2: 前端接口401 Unauthorized？
A: 检查是否已登录，token是否过期，后端JWT配置是否正确。

### Q3: 学生端无法发现教师端？
A: 确保两台电脑在同一局域网，防火墙允许UDP 8888和HTTP 5000/5001端口。

### Q4: 设备导入失败？
A: 检查Excel格式是否符合模板，实验室名称和责任人是否存在于系统中。

### Q5: AI助手无响应？
A: 检查通义千问API密钥配置，确保网络可以访问API地址。
