# 教师角色暂停

教师角色暂时停止使用。历史账号、角色记录、教师页面、课程环境、课表接口和教师客户端源码均保留。
不执行数据库删除、批量更改角色或数据迁移。

- Web 不注册教师业务路由，也不展示教师菜单；旧教师链接进入无权访问页。
- 登录、会话写入、服务端资料读取及已有 JWT 均拒绝教师角色。
- 用户管理不再提供新增或批量分配教师角色，历史教师账号显示“角色已停用”。
- 管理员仍可查看历史账号，并为其选择其他当前可用角色。
- 缺少角色时必须明确选择，不再默认创建教师账号或自动提升为管理员。

角色暂停规则在前端 `web/src/constants/auth.js` 的 `RETIRED_ROLE_VALUES` 和
后端 `Backend/src/main/java/org/example/backend/security/RetiredRoles.java` 的 `VALUES` 中集中维护。
未来恢复时，应同时移除两端集合中的 `teacher`、`教师`，恢复用户管理的教师选项，
移除路由中的教师兜底拦截，并更新对应回归测试和功能结构图。

教师客户端的主机心跳、实验室设备状态和激活码中的客户端类型属于设备能力，
不等同于平台教师账号角色；现有客户端接口、管理员查看和设备管理代码保持可用。

功能结构图同步为“系统管理员”和“实验室管理员”两个分支，位于 `docs/智云实验室-功能结构图.drawio`。
