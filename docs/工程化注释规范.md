# 工程化注释规范

本规范补充文件职责说明，面向维护、联调和故障排查。注释应描述代码真实具备的保证，不能把期望行为写成已实现的能力。

## 接口契约

Java 方法使用 JavaDoc；JavaScript/TypeScript 使用 JSDoc；Python 保留已有 docstring，为其余函数补充定义前的说明；Rust 使用 rustdoc。按当前项目要求，简单 getter、setter、构造方法和转发方法也保留简短用途说明。匿名回调和模板中的箭头函数在定义处说明处理意图，避免只补文件头而遗漏实际函数。

需要明确的内容：

- 输入：是否必填、允许范围、格式、单位、时区、数据来源及信任边界。
- 输出：直接对象还是包装结果、是否可能为空、是否返回新对象、是否修改入参。
- 失败：参数错误、业务拒绝、外部能力不可用及并发状态变化分别如何表达。
- 副作用：数据库写入、网络访问、文件写入、环境变量传递和 DOM 资源分配。

已有示例：

| 关注点 | 源码位置 | 约定 |
| --- | --- | --- |
| 能力结果 | `Backend/src/main/java/org/example/backend/service/CapabilityResult.java` | 先检查可用状态，再检查载荷；工厂方法并不保证载荷非空 |
| 时间转换 | `Backend/src/main/java/org/example/backend/service/ReservationTimeRangeParser.java` | 严格同日 HH:mm-HH:mm，使用 Asia/Shanghai 转为绝对时间 |
| 服务端记录 | `web/src/api/services/authoritativeRecord.js` | 正式响应校验安全整数 ID，禁止拿客户端提交对象伪装成已保存记录 |
| 本地分页 | `web/src/composables/useTablePagination.js` | 对浏览器已有数组切片，不是服务端分页 |

## 事务、并发与重试

事务说明必须包含生效入口和实际隔离策略。`DefaultReservationCreationService` 的串行化事务通过 Spring Bean 公开方法入口生效；没有内置自动重试或请求幂等去重，不能写成“提交永远不会重复”。

`ReservationPersistenceService.updateReview` 通过记录 ID 和旧状态集合进行条件更新。零行更新由上层视作记录不存在或状态已变化；这不是通用版本号锁，也不能代表所有跨记录的并发问题都已解决。

课表锁是单 JVM 的互斥标记，不是分布式锁。脚本等待上限以单次脚本、秒为单位；WebDriver 轮询上限不包含无限制的底层阻塞保证。可视恢复最多一次，不绕过学校授权。

Rust 共享状态说明需要指出锁持有范围。复制快照后再执行网络 I/O；等待工作线程退出前先释放它们仍可能访问的 Mutex。不要将不同线程的状态更新时间写成同一个原子事务。

## 生命周期与性能

分配资源的地方要说明谁释放、何时释放：

- `useECharts` 卸载时 dispose 图表，调用方负责注册和清理窗口尺寸监听。
- `attachLiquidGlass` 返回幂等释放函数，清理按需创建的 SVG、指针监听器、共享滚动订阅和待执行帧；使用上游 standard 折射核心，避免运行时 Worker 路径依赖。仅背景经过滤镜，文字不参与位移。滚动期间暂停背景采样，空闲按钮不常驻 SVG 或 transform 合成层。
- `AssistantWebSocket` 不内置重连或离线发送队列，组件卸载时调用 disconnect。
- 学生端后台上报线程随进程存续，不提供单独取消句柄。

性能注释解释成本来源及边界，不填写未经测量的耗时或并发能力。HTTP 直方图产生额外时序；监控标签避免用户 ID、完整 URL 等高基数维度。

## 协议与安全

写清端口用途、消息类型、采样参数和字段归属，不能在注释中保存真实令牌、账号密码或用户数据。

- JWT 载荷仅编码、不加密，不存放密码等秘密。
- 匿名监控采集以实际接收请求的本地管理端口判断，不信任请求方提供的 Host。
- 助手 hello 的 PCM 参数与服务端保持一致；发送帧成功不等于业务已确认完成。
- 学生消息校验按实际逻辑描述：实验室必须匹配，教师配置了非空 token 才校验 token。

## 维护要求

变更契约时同时修改实现、调用方、注释和对应测试。需要保留待办时注明具体问题与完成条件，不添加没有依据的“以后优化”或虚构工单号。

全项目覆盖清单是文件级阅读索引；更详细、更新后的契约以源码中的方法和类型注释为准。SQL 迁移文件保持原文，避免触发 Flyway 校验和变化；Mapper XML 中的算法说明可随映射维护。
