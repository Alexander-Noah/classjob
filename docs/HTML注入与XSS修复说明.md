# HTML 注入与 XSS 修复说明

本次围绕用户输入如何进入网页、打印文档、下载 SVG、图片代理和桌面 WebView 检查并修复。没有对姓名、说明等普通文本统一删除尖括号，也没有对数据库内容重复编码；安全控制放在实际输出上下文。

## 已完成

1. **AI 消息不再通过 v-html 显示。** 消息解析为受控的段落、列表、强调和代码节点，再使用 Vue 文本节点输出。输入 `<script>`、`<img onerror>`、`<svg onload>` 会作为文字显示。保留原有排版和流式代码块行为，HTML 导出格式化函数继续对文本转义。
2. **共用地址白名单。** 图片地址拒绝 javascript、vbscript、file、HTML/SVG data URL、非本系统创建的 blob 引用、反斜杠和协议相对地址。允许 HTTP/HTTPS、平台相对地址及明确的 PNG/JPEG/GIF/WEBP data 图片。IoT 视频跳转也经过 HTTP/HTTPS/相对地址检查，保留 noopener。
3. **头像地址前后端均校验。** 后端账号接口拒绝可执行协议及携带用户名密码的远程地址；前端显示已有历史头像时也执行白名单检查。组件内部自行创建的头像预览对象 URL 仍可使用。
4. **打印标签增加隔离。** 继续对设备名称、责任人、维护及盘点记录逐项转义，二维码地址也按 HTML 属性转义。删除打印 HTML 中的内联脚本，改为由父页面设置打印回调；打印文档采用禁止脚本的 CSP。
5. **下载二维码 SVG 的选项不能注入标签。** 颜色仅允许十六进制色值，边距只允许 0–64 的整数，阻止通过可配置颜色或尺寸逃逸 SVG 属性。
6. **Web 与桌面端配置 CSP。** Web/教师端 HTML 入口和三份 Tauri 配置禁止内联脚本、嵌入对象及非预期 base 标签。没有加入 unsafe-inline 脚本或 unsafe-eval 来绕过限制。
7. **头像与摄像头代理不再继承上游的活动文档 MIME。** 仅 PNG/JPEG/GIF/WEBP 内联显示；上游返回 HTML、SVG、JavaScript 或其他类型时，使用 application/octet-stream 并按附件下载。响应添加 nosniff 和 sandbox CSP。全局安全头过滤器不再覆盖接口已经设置的更严格 CSP。

项目源码扫描未发现其他 v-html、innerHTML、outerHTML、insertAdjacentHTML 或 srcdoc 显示入口。保留的 document.write 仅用于固定模板的打印页面，动态内容均转义，页面禁止脚本。普通表单列表继续使用 Vue 文本插值。
