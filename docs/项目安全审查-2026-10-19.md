# 项目安全审查

审查日期：2026-10-19，基于当前工作区（包含尚未提交的修改）。本次仅审查和验证，未修复业务代码，未对真实设备发送控制命令，未写入实际数据库。

## 结论与范围

当前最优先的问题是：局域网设备控制接口缺少认证、云端主机登记可被冒充、登录令牌不能及时撤销，以及两条服务端请求伪造（SSRF）入口。图片验证码不能补足这些边界。

范围覆盖 Backend Java 后端、web 管理前端、TvTa-ui-main 教师端、zhiyun-student-client 学生端、Python 导入脚本、数据库初始化文件、监控及 CI 配置。进行了重点调用链人工检查、危险调用搜索、本地合成数据探针、已有安全测试和两个 JavaScript 锁文件的联网漏洞检查。不是逐行形式化验证，也不是生产环境渗透测试，不能据此声称找出了所有漏洞。

严重性按本项目可达条件评定；“高”不表示已发生入侵。下文区分当前代码缺陷、需要部署条件才能触发的问题，以及已被停用角色挡住的潜在问题。
